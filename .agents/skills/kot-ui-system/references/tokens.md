# Визуальный язык kot

[Каталог](../assets/tokens.json) содержит назначение и точное значение каждого токена. Имя ключа совпадает с именем в исходнике после двух дефисов. Поле `value` задаёт базу для обеих тем, поле `light` переопределяет значение в светлой. Сохраняй отдельные роли, даже когда числа совпадают. Так `section-gap` и `space-md` могут развиваться независимо. В светлой теме `strategy-ink` по-прежнему равен `#26331c`, общий `ink` равен `#25301c`.

## Первый экран

1. Опиши предмет работы и основную команду. В редакторе зрительный центр занимает кадр, порядок сцен виден на таймлайне, длительность клипа определяет его ширину. В VPN-клиенте первичны состояние соединения и выбранный сервер. Панели и навигацию спроектируй вокруг этих задач.
2. Назначь ролям компоненты. Окно использует `bg/text`, боковая область `side`, панель `surface/radius-panel`, вторичная кнопка при наведении `raised`. Разделитель использует `line`. Для вторичного текста проверь `muted` именно на фоне его поверхности. Основное действие использует `accent/ink`. Для важного мелкого текста при недостаточном контрасте возьми `text`.
3. Основной текст набери комплектным Manrope, `font-body/weight-body`. Для акцента возьми `weight-emphasis`, для подписи, пояснения и надписи кнопки соответствующие `font-caption/detail/control`. Примени `line-body` как множитель текущего кегля. Для кнопки используй фиксированный `line-control`. Каталог задаёт `font-ui` вместе с резервным системным sans-serif. Проверь фактически загруженный Manrope на кириллице, цифрах и символах.
4. Собери кнопку с минимальной высотой `control-height` и `radius-compact`, поле с `field-height` и `radius-control`, диалог с `dialog-pad` и `radius-dialog`. Внутри групп используй шкалу `space-*`, между секциями `section-gap`. На крупном системном тексте дай контролу вырасти. Ширина рабочей области, соотношение сторон видео и горизонтальный масштаб времени следуют данным продукта.
5. Добавь состояния только к применимым действиям. Вторичная кнопка меняет фон на `raised` при наведении. Доступная кнопка при нажатии масштабируется относительно центра на `scale-press`; геометрический переход использует `motion-normal` и `ease`. Для цвета контрола используй `motion-control`. Для фокуса от клавиатуры возьми весь `focus-ring`, обеспечь просвет и место под обводку. Выбор сцены обозначь границей `detail`, отметкой и семантикой выбора. При недоступности совмещай `opacity-disabled` с нативным disabled. Для ожидания покажи статус операции, для ошибки используй `danger` и объяснение. Цвета рекомендации `strategy-*` относятся к рекомендации стратегии.
6. Вход слоя, выход, подложка и подсказка имеют собственные длительности. Используй соответствующие роли. Тень `shadow-toast` предназначена для плавающего уведомления. Уважай системные настройки контраста, масштаба текста и reduced motion. Подробности движения и прерывания есть в [Motion](motion.md).

## Получение ресурсов

Из каталога скилла выполни команду с Python 3.9 или новее. На Windows можно использовать `py -3` вместо `python`.

```sh
python scripts/export_tokens.py MyApp/KotTheme
```

Экспорт создаёт `web/kot.css`, `wpf/dark.xaml`, `wpf/light.xaml` и шрифты с лицензией OFL. Для веба подключи `KotTheme/web/kot.css` перед стилями продукта. На корневом элементе выставляй класс `theme-light` для светлой темы, тёмная тема задана в корне. При открытии выбери сохранённую тему или системное предпочтение до первого видимого экрана. Загружай шрифт с указанного относительного пути.

```css
.export {
  background: var(--accent);
  color: var(--ink);
  font: var(--weight-emphasis) var(--font-control)/var(--line-control) var(--font-ui);
  min-height: var(--control-height);
  border-radius: var(--radius-compact);
}
.export:focus-visible { outline: var(--focus-ring); }
```

В WPF положи `KotTheme` в корень проекта, включи словари как Page, файлы TTF как Resource. В App.Resources подключи нужный словарь через MergedDictionaries. При смене темы замени словарь на том же месте. На элементах используй DynamicResource. Шрифты подключаются относительно XAML-словаря. Экспорт добавляет типизированные представления роли для свойств с разным типом. [Упаковка шрифтов в WPF, Microsoft Learn](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/packaging-fonts-with-applications)

```xml
<Border Background="{DynamicResource Kot.surface}"
        Padding="{DynamicResource Kot.space-md.inset}"
        CornerRadius="{DynamicResource Kot.radius-panel.corners}">
  <TextBlock Foreground="{DynamicResource Kot.text}"
             FontFamily="{DynamicResource Kot.weight-body.face}"
             FontWeight="{DynamicResource Kot.weight-body}"
             FontSize="{DynamicResource Kot.font-body}"
             LineHeight="{DynamicResource Kot.line-body.at-body}"
             LineStackingStrategy="BlockLineHeight" Text="Длительность сцены"/>
</Border>
```

| Тип каталога | Что передать нативному рендереру |
| --- | --- |
| color | Цвет sRGB по каналам и тематическая кисть. Учитывай порядок RGBA/ARGB у целевой платформы. |
| length | Логические единицы при 96 DPI. На Windows 1 такая единица соответствует 1 DIP. Отступы и радиусы передавай как Thickness и CornerRadius. Масштаб устройства применяется один раз. |
| fontStack, fontWeight | Для движка с поддержкой variable fonts используй Manrope.ttf с осью wght от 200 до 800. Для WPF приложены статические экземпляры на 500 и 650 из того же файла. Используй ресурс веса и соответствующий `.face`. Локальные имена семейств даны в словаре. |
| ratio | У `line-body` умножай на текущий размер текста. При 14 результат 22.4 DIP. `line-control` уже содержит 20 DIP. У состояния это соответственно доля непрозрачности или коэффициент масштаба. |
| duration, bezier | Каталог хранит миллисекунды и четыре координаты кубической кривой. В WPF словарь содержит Duration и KeySpline. В другом стеке создавай интерполятор по тем же контрольным точкам. |
| outline | Ширина, сплошная линия, тематическая ссылка на `detail`. В WPF это кисть `Kot.focus-ring` и Thickness `Kot.focus-ring.width`. Нарисуй их в слое фокуса без сдвига соседа. |
| shadow | Тень уведомления имеет смещение (0, 10), размытие 30, растяжение 0, чёрный цвет с альфой 0.2. В WPF это DropShadowEffect вниз, глубина 10. Из-за разных алгоритмов размытия сравни видимый край и плотность на целевой платформе. |

Для других стеков тот же JSON читается без CSS. Например, в Qt сформируй тематические QBrush и логические размеры, зарегистрируй Manrope как шрифт приложения, задай вес по шкале используемой версии Qt. Сравни реальный штрих и ширину строки на комплектных весах. На платформе с другой системой логических единиц сначала сопоставь масштаб 100%, затем проверь системное масштабирование. Если платформа принудительно управляет цветами или размером текста, сохраняй доступность и документируй сопоставление ролей.

## Обоснованные исключения

Вначале попробуй существующую роль или семантическую ссылку на неё. Для нового требования запиши в проекте: элемент и задача, неподходящая роль, выбранное значение или формула, область действия, поведение в двух темах и способ проверки. Пример из редактора: превью титра имеет размер шрифта от 22 до 42 логических пикселей, зависящий от ширины окна. Это текст самого видеокадра, его нужно читать при уменьшении превью. Исключение действует лишь внутри кадра. Подписи, транспорт и кнопки используют штатную типографику. Пропорции клипов задаются секундами. Аналогично пользовательская высококонтрастная тема замещает кисти в пределах своей настройки. Имена локальных дополнений помечай префиксом продукта, общую роль меняй только при отдельном решении для всей системы.

## Проверка с нуля

Распакуй скилл в пустую папку. Из корня распакованного скилла выполни:

```sh
python evals/token_parity.py
python scripts/export_tokens.py examples/windows-editor/KotTheme
dotnet build examples/windows-editor/Editor.csproj -c Release
```

Для сборки примера нужны .NET 10 SDK и пакет WebView2 из NuGet. На Windows с .NET Desktop Runtime 10 и WebView2 Runtime открой его командой `dotnet run --project examples/windows-editor/Editor.csproj`. В редакторе на WPF + WebView2 нативная строка состояния привязана к кистям и Manrope словаря WPF. Предпросмотр и таймлайн используют веб-ресурсы того же каталога. Сам HTML можно открыть в браузере после экспорта. Код VPN-клиента для этих действий не нужен.

- При переключении темы проверь окно, строку состояния, панели, текст на акценте, разделители и контур Tab. Для статичного сравнения бери тот же клип, размер окна и масштаб. Сравни фактический цвет и размер контрола, затем пиксели снимка. Одинаковая геометрия в обеих темах позволяет отличить смену цвета от сдвига.
- Выбери «Линии города» на таймлайне. Предпросмотр и таймкод должны показать ту же сцену. На первом и последнем клипе соответствующая стрелка недоступна. Пройди до «Экспорт» клавишей Tab, открой и закрой диалог через Escape, проверь возвращение фокуса. Зажми и отпусти кнопку, переключи тему при открытом экране. В обеих темах проверь масштаб 100%, 125% и 150%, включая небольшой размер окна и reduced motion.
- Для проверки в Chromium установи Playwright для Python и его Chromium. После экспорта выполни `python evals/editor_visual.py`. Ключ `--screenshots КАТАЛОГ` сохраняет кадры. Прогони тот же путь в нативном окне Windows перед приёмкой его отрисовки.
- Для проверки ресурса измени `accent` или `control-height` в тестовой копии каталога и повтори экспорт. Основная команда должна получить новое значение. Случайная литеральная заливка или высота в компоненте проявится как расхождение при проверке вычисленного стиля.

## Синхронизация с источником

При обновлении клиента сопоставь декларации `:root` и `.theme-light` с JSON по имени, типу, назначению и наследованию. Новые роли получат описание, новый тип потребует явного конвертера. Обнови SHA-256 источника после сверки. Из корня скилла запусти `python evals/token_parity.py --source ../../../Windows/ui/styles/tokens.css` с фактическим путём к исходнику. Проверка сверяет базовые значения и все переопределения, затем заново экспортирует и считывает обе темы. При смене Manrope обнови исходный файл, оба статических экземпляра оси wght и лицензию.
