Меню трея теперь выглядит как часть kot.: тема, цвет, статус подключения, выбранный сервер и быстрые переходы к серверам, логам и настройкам.

- Левый клик по иконке трея открывает окно.
- Сворачивание оставляет окно на панели задач. Повторный клик по активной кнопке тоже сворачивает его.
- Развёрнутое окно после сворачивания возвращается в прежний размер.
- «Закрывать в трей» отвечает только за крестик.
- README и тексты приложения обновлены. kot. называется приложением на базе sing-box.
- Чтение локального API ограничено по размеру; настройки GitHub и сборки проверены и усилены. Подробности в [отчёте](https://github.com/prodkot/kot/blob/main/SECURITY-AUDIT.md).

[Установщик для Windows x64](https://github.com/prodkot/kot/releases/download/v0.4.2/Kot-Setup-0.4.2-Windows-x64.exe) · [Portable ZIP](https://github.com/prodkot/kot/releases/download/v0.4.2/Kot-Client-0.4.2-beta-Windows-x64.zip)

Подписки и HWID сохраняются при обновлении. Обновление с GitHub установится само, если включена автоматическая установка. Нужна Windows 10 или 11, x64.
