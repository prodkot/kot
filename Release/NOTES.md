Экспериментальный полный переход на Xray.

Исправления предварительного выпуска `v0.8.0-xray.4`:

- Журнал фиксирует текст и положение прокрутки, когда пользователь листает вверх или выделяет строки. Новые события и обрезка начала длинного журнала больше не сдвигают читаемый фрагмент и не сбрасывают выделение.
- Кнопка «К новым записям» возвращает к живому журналу. Пауза, поиск, фильтр уровня и копирование полного журнала сохранены.
- Убрана пустая вкладка «Соединения»: в текущем Xray нет полноценного списка активных клиентских соединений. Страница сразу открывает журнал без вкладок. Общие счётчики доступны в статистике.

Исправления предварительного выпуска `v0.8.0-xray.3`:

- Исправлен DNS в нативном TUN Windows: DNS-серверы используют соседние адреса `172.28.231.2` и `fdfe:dcba:231::2`, а не собственные адреса адаптера. Запросы теперь попадают в Xray. Правила DNS провайдера и защита от утечек сохраняются.
- Подключение и фоновая проверка TUN дополнительно проверяют разрешение имени через DNS Windows. Ответ через HTTP-прокси сам по себе больше не считается достаточным. При сбое DNS подключение завершается понятной ошибкой, ядро останавливается, kill switch сохраняется.
- Windows-регрессия воспроизводит отказ старой конфигурации, проверяет оба DNS-адреса, системные запросы A/AAAA без заранее заполненного кеша, повторное подключение и рабочий XHTTP при сломанном клиентском DNS.

- Единственное сетевое ядро: официальный Xray, исходники закреплены на 0f3d884786f9ec73d3be8899cb6b9e1e6dd3c41e. Это сборка текущих исходников upstream с собственным TUN, а не стабильный релиз Xray.
- Переход с 0.7.x: вручную запустите новый Setup поверх установленного клиента. Старый встроенный обновлятор не принимает пакет только с Xray. Эксперимент не предлагается как стабильное автообновление.
- sing-box и libcronet.dll исключены из установщика. Wintun 0.14.1 взят из официального подписанного архива с проверкой SHA-256.
- TUN IPv4/IPv6, DNS, XHTTP, обычные протоколы, серверные правила и локальные профили работают через Xray. Существующие подписки и резервные копии сохраняют свой формат.
- Автовыбор проверяет серверы отдельными процессами Xray при подключении и по заданному интервалу. Переключение сервера переподключает туннель. Полные серверные конфиги сохраняют собственные DNS и маршрутизацию.
- GeoIP использует проверяемые списки CIDR Loyalsoldier, без зависимости от формата SRS.
- Сохраняется постоянная защита WFP при падении ядра. Проверки доступности отделены от обходных маршрутов.
- Статистика получает реальные суммарные счётчики Xray. Подробные счётчики по соединениям и приложениям недоступны: Xray их не предоставляет. Новые данные учитываются как нераспределённый трафик, старая история сохраняется.

Это предварительная сборка для проверки на Windows. Стабильная ветка main и релиз 0.7.3 не изменены. Перед установкой экспериментальной версии сохраните резервную копию профиля в настройках клиента. INCY не изменялся.
