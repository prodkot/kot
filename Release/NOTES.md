- Закрытие диалогов завершается даже при зависшей анимации, фокус возвращается на доступный элемент, а запоздалые ответы HWID не попадают в повторно открытое окно.
- В зависимости WebSocket устранено использование слабого генератора маски кадров (GO-2026-6278). Версия ядра Xray и настройки подключения сохранены.
- На заставке работает фирменный знак k. с живой квадратной точкой. Движение учитывает уменьшение анимации и останавливается в скрытом окне. Готовность приложения не зависит от завершения жеста.
- Проверка пинга сохраняет подсветку, фокус и доступность карточки сервера. Повторный запрос блокируется только для проверяемого сервера, другой сервер можно поставить в очередь. Отмена завершает активные и ожидающие проверки.
- Меню действий сервера использует общую анимацию kot, два текстовых пункта с разделителем и сохраняет клавиатурную навигацию. Позиция учитывает границы окна и масштаб интерфейса.
- При однозначном совпадении имени и остальных параметров VLESS REALITY обновление IP и shortId сохраняет выбранный сервер. Текущее подключение продолжает работать, следующее использует обновлённую конфигурацию. Неоднозначные совпадения требуют явного выбора.
- В меню сервера можно посмотреть JSON после разбора и перед подключением к Xray. Оба представления сразу показывают полный JSON. Копирование находится внутри области кода, размеры диалога сохраняются при загрузке, ошибках и переключении вкладок.
- При обновлении kot сохраняет сервер после переименования, смены регистра UUID и однозначной ротации клиентских учётных данных. Действующее подключение продолжает работать. Если прежний сервер исчез или совпадение сомнительно, для нового подключения нужен явный выбор.
- При сворачивании и раскрытии боковой панели иконки и подписи перемещаются с субпиксельной точностью. Нижняя кнопка становится квадратной за счёт изменения ширины.
