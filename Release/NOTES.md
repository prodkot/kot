Первый выпуск kot. на GitHub.

### Что изменилось

- Официальная сборка уже знает адрес `prodkot/kot` и может получать отсюда обновления.
- Исправлена остановка sing-box: приложение корректно дожидается своего ядра и получает код выхода.
- Исправлена сборка установщика на Windows. Установщик и подписанный ZIP теперь собирает GitHub Actions.

### Установка

Для обычной установки скачай **[Kot-Setup-0.4.1-Windows-x64.exe](https://github.com/prodkot/kot/releases/download/v0.4.1/Kot-Setup-0.4.1-Windows-x64.exe)**.

Если хочешь без установки, распакуй [portable ZIP](https://github.com/prodkot/kot/releases/download/v0.4.1/Kot-Client-0.4.1-beta-Windows-x64.zip) целиком и запусти `Kot.exe`. Нужна Windows 10 или 11, x64. Если нет WebView2, запусти комплектный `Install-WebView2.exe` с интернетом.

Для обновления с присланной раньше 0.4.0 открой **Настройки → Обновления**, выбери GitHub, укажи `prodkot/kot` и сохрани источник. Затем нажми «Проверить» и «Обновить». Подписки, настройки и HWID сохранятся. Включённая автоматическая установка будет сама ставить следующие выпуски, пока приложение работает.

### Пока beta

Сборка и проверки [прошли на Windows в GitHub Actions](https://github.com/prodkot/kot/actions/runs/37638153111). Подпись опубликованного ZIP проверена прежним клиентом 0.4.0. Полный сценарий установки и обновления с настоящими окнами, а также сетевые утечки ещё требуют ручной проверки. Kill switch пока нет, установщик без сертификата Windows.
