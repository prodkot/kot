# Изменения в kot.

Для ошибки открой [Issue](https://github.com/prodkot/kot/issues) с версией клиента и Windows, шагами воспроизведения и ожидаемым результатом. Скриншоты и очищенные логи помогают. Ссылки на подписки и данные серверов публиковать не нужно. Уязвимости сообщай [приватно](SECURITY.md).

Для изменения кода создай отдельную ветку и pull request. Опиши проблему, итоговое поведение и выполненные проверки. Изменения интерфейса сопровождай скриншотом. Тесты должны проверять поведение, особенно восстановление настроек Windows, отмену операций и ошибки обновлений.

Команды сборки и проверок находятся в [docs/BUILD.md](docs/BUILD.md), выпуска версии в [Release/GITHUB.md](Release/GITHUB.md). Версии зависимостей и GitHub Actions должны быть закреплены; при добавлении компонента обнови [THIRD-PARTY.txt](THIRD-PARTY.txt) и тексты в `licenses/`.

В исходники не входят сборки, кэш, профили пользователей и приватный ключ издателя. Нужные runtime-файлы и лицензии формирует сборка; пользовательские файлы при установке не удаляются по расширению.
