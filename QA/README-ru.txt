kot 0.8.0, кандидат для проверки Windows

1. Установите приложенный Setup поверх kot. Перед установкой сохраните резервную
   копию через настройки клиента. SDK и другие инструменты устанавливать не нужно.
2. Распакуйте этот архив целиком. Запустите Start-Checks.cmd двойным щелчком.
   Выберите установленный Kot.exe, если он не найден автоматически.
3. После проверки отправьте qa-report.zip из папки набора.

Автоматическая часть не требует администратора, не меняет DNS, маршруты, прокси,
WFP, профиль или подписки. Она сверяет точные SHA-256 файлов с проверенной сборкой,
проверяет версию Xray, WebView2, принятие синтетической конфигурации и реальный
локальный трафик через VLESS. Это НЕ проверка вашего VPN и НЕ проверка TUN.
Локальные процессы и конфигурации удаляются в finally. Для проверки не требуется
интернет. Если окно было принудительно закрыто, следующий запуск удалит собственные
остатки. Скрипт никогда не завершает процессы клиента или чужие процессы Xray.

Затем скрипт предложит три короткие ручные проверки. Их можно пропустить цифрой 3.
Перед подключением, сном и сменой сети показано предупреждение о правах и обрыве сети.
Если после ручного опыта сеть не восстановилась: откройте kot через трей,
нажмите «Отключить». При включённом Kill switch отключите его в настройках, только
если хотите разрешить прямой интернет. Эти действия скрипт автоматически не делает.

Отчёт содержит только фиксированные результаты, версии, контрольные суммы,
номер коммита, версию ОС, тип/код ошибки запуска. Нет сырых журналов, конфигураций,
подписок, UUID подключения, имён ПК, пользователей, серверов, IP и содержимого буфера
обмена. Ничего никуда не отправляется. Подписки и настройки не читаются.

Если пакет не совпадает, скрипт не запускает неизвестное ядро. Проверяйте именно
Setup того же коммита. Старый qa-report.zip сохраняется как qa-report.previous.zip.
