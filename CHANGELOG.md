# Что нового

## 0.5.5

- Убраны README, отчёты и инструкции из установленного приложения.
- Все лицензии собраны в папке licenses; добавлены уведомления зависимостей sing-box.
- После обновления удаляются устаревшие документы и завершённая временная папка обновления.

## 0.5.4

- Флаг сервера перенесён из названия в значок слева.
- Для серверов без флага добавлен белый кружок.

## 0.5.3

- Новый список подписок в стиле приложения: количество серверов, отметка выбранной и быстрое добавление.
- Подсветка сервера теперь охватывает всю строку, включая избранное и пинг.

## 0.5.2

- Флаги стран в названиях серверов теперь отображаются картинками, без зависимости от шрифтов Windows.
- Исправлено отображение флагов на главном экране, в списке серверов и в маршрутах соединений.
- Флаги встроены в программу и работают без загрузки из интернета.

## 0.5.1

- В настройках осталась кнопка «Проверить обновления»: проверка запускается сразу.
- Убраны VPS, выбор репозитория и обновление из файла. Обновления загружаются из официального репозитория на GitHub.
- Старые настройки источника больше не влияют на обновления. Автоматическая установка сохранена.

## 0.5.0

- Добавлен kill switch: блокировка прямого интернета при сбое соединения, включая IPv4 и IPv6.
- Исправлено мигание и повторная анимация при открытии разделов.
- Для установки и обновления теперь используется один Setup. Portable-сборки убраны.
- Обновление из файла принимает Setup вместо ZIP.
- Установщик сам закрывает предыдущую версию перед установкой.
- Удаление программы снимает блокировку kill switch.
- Исправлено зависание при удалении, если автозапуск уже выключен.
- Сокращён README, убраны дубли и устаревшие документы.

## 0.4.2

Новое меню трея с темами и быстрыми переходами. Окно нормально сворачивается на панель задач и восстанавливает прежний размер. Крестик и кнопка сворачивания больше не делают одно и то же. Тексты обновлены, чтение локального API ограничено по размеру, настройки сборки усилены.

## 0.4.1

- Первый выпуск на GitHub. У официальной сборки источник обновлений уже настроен на `prodkot/kot`.
- Исправлено завершение sing-box: приложение ждёт свой запущенный процесс и корректно читает код выхода.
- Исправлена сборка установщика на Windows. GitHub Actions собирает установщик и подписанный ZIP.

## 0.4.0

- Обновления скачиваются и устанавливаются автоматически, если включена соответствующая настройка.
- После установки приложение перезапускается; при ошибке замены файлов или запуска интерфейса предусмотрен откат.
- Появился установщик для Windows и номер версии рядом с `kot.` в заголовке окна.
- Исправлены мелкие проблемы интерфейса и повторные нажатия во время долгих операций.

## 0.3.1

## 0.3.0

- Скорость скачивания и отправки на главном экране.
- Встроенный Manrope, включая кириллицу, без загрузки шрифта из интернета.
- Проверка и скачивание обновлений с GitHub или VPS.

## 0.2.x
