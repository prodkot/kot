# Начало работы с kot

Для любого агента и участника проекта:

1. Прочитай [AGENTS.md](AGENTS.md): правила работы распространяются на всё дерево репозитория.
2. Прочитай [жизненный цикл версий](Release/LIFECYCLE.md): это постоянный источник правил Dev, Beta, локального кандидата Beta и Stable. Не определяй готовность по имени ветки или версии.
3. Проверь текущую ветку, коммит и незакоммиченные изменения. Используй отдельную ветку, сохраняй чужую работу и ограничения текущей задачи.
4. Для реализации используй [архитектуру](docs/ARCHITECTURE.md) и [матрицу проверок](docs/VALIDATION.md); перед изменениями UI следуй указанным в AGENTS.md инструкциям kot-ui-system.
5. Перед передачей сборки сверь [идентичность](Release/BUILD-IDENTITY.md), [Windows-приёмку](Release/DEVELOPMENT.md) и [порядок публикации](Release/GITHUB.md). Сборка, приёмка и публикация являются разными действиями.

Документация не разрешает публикацию, слияние в main или замену опубликованного установщика без явного разрешения владельца. Невыполненные и недоступные проверки остаются открытыми при передаче между агентами. Обзор остальных документов: [docs/README.md](docs/README.md).
