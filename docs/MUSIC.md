# Музыка в «О приложении»

Библиотека живёт в отдельной ветке `music`, в папке `music`. Она обновляется независимо от установщика и сайта.

1. Открой [загрузку музыки на GitHub](https://github.com/prodkot/kot/upload/music/music).
2. Перетащи аудиофайлы, нажми **Commit changes** в ветку `music`.
3. Открой «О приложении» в kot. Новые треки появятся после обновления списка. Повторный запрос выполняется не чаще раза в пять минут; GitHub также может ненадолго кешировать файл.

Проще всего использовать MP3 или OGG. Поддерживаются также M4A, WAV, FLAC и WebM, если их кодек доступен в WebView2. До 20 МиБ на файл, до 100 треков, без вложенных папок. Название в плеере берётся из имени файла без расширения. Файлы общедоступны. Загружай музыку, которую можно распространять.

Первое нажатие воспроизведения выбирает случайный трек. Пауза и повторное нажатие продолжают его с прежней позиции, даже если список обновился. По окончании или нажатию «Другой трек» выбирается следующий случайный файл; при нескольких треках текущий не повторяется подряд. Закрытие окна ставит музыку на паузу. При запуске приложения музыка сама не включается.

Чтобы удалить или заменить трек, измени файл в той же папке через GitHub. Пересобирать kot., вручную составлять JSON или запускать Actions не нужно. Для запроса списка не используются токены. При недоступном GitHub плеер показывает ошибку и позволяет повторить запрос. Отсутствие треков не мешает работе VPN.
