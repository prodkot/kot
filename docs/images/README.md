# Изображения документации

На главной странице репозитория показаны [главный экран](readme/connection-demo-084.png) и [список серверов](readme/servers-demo-084.png) версии 0.8.4. Снимки сделаны в браузерном демо с интерфейсом клиента и демонстрационными данными; состояние подключения и показатели имитируются. Из главного экрана собрана композиция [showcase-demo-084.png](readme/showcase-demo-084.png). Схема [first-connection.svg](readme/first-connection.svg) показывает основные шаги подключения. Прежние снимки 0.8.3 сохранены как [главный экран](readme/connection.png) и [серверы](readme/servers.png).

В этой папке также хранятся фирменный баннер `cover.svg` и снимок главного экрана версии 0.8.0 `overview-dark.png`. Снимки для сайта находятся в `site/assets`.

`routing-dark.png`, `geoip-dark.png` и `statistics-dark.png` иллюстрируют отдельные руководства. Это снимки интерфейса, а не доказательство сетевых измерений.
