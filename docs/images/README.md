# Изображения документации

## Оформление репозитория

`cover.svg` использует векторную надпись и актуальный абстрактный знак из [Brand](../../Brand/README.md). Он самодостаточен: шрифты, скрипты и внешние ресурсы не нужны.

Снимки для главного README показывают HTML-интерфейс **kot. 0.7.1** из `Windows/ui`:

| Файл | Что показано |
| --- | --- |
| `overview-dark.png` | Главный экран, тёмная тема |
| `overview-light.png` | Тот же экран, светлая тема |
| `servers-current.png` | Выбор сервера, избранное и пинг |
| `statistics-current.png` | Время сеанса и статистика в светлой теме |

Они сняты через Playwright с тестовым WebView-мостом из [Tests/statistics_ui.py](../../Tests/statistics_ui.py). Имена серверов, состояние соединения, пинг и трафик заданы для демонстрации. Нативное окно Windows и реальное сетевое соединение эти снимки не проверяют. Масштаб снимков: 1,5 пикселя на CSS-пиксель; размер окна подключения 960 × 640, серверов 960 × 900, статистики 960 × 1200.

При изменении интерфейса обновляй обе темы главного экрана вместе, проверяй версию в заголовке и сохраняй пояснение о демонстрационных данных. В README светлая и тёмная версии переключаются через `<picture>` по цветовой теме читателя.

Остальные изображения используются в отдельных руководствах и могут показывать предыдущие версии интерфейса.
