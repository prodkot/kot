Сеть при съёмке заблокирована. Снимки не подтверждают работу VPN, установщика или Windows WebView2 и не содержат пользовательских подписок или секретов.

## Повторить съёмку

Нужны Python, Playwright и Chromium. Из корня репозитория запусти:

```sh
python3 docs/images/capture.py
```

[Скрипт](capture.py) использует мост из `Tests/statistics_ui.py`, задаёт фиктивное время и данные, снимает обе темы и обновляет [capture.json](capture.json). В манифесте записаны коммит, версия браузера, размеры, SHA-256 исходников UI и изображений. Номер версии берётся из `Directory.Build.props`; номер сборки не имитируется. После пересъёмки проверь кадры глазами и обнови подписи в README и галерее.

`cover.svg` остаётся фирменным баннером. `overview-dark.png` хранится как исторический снимок 0.8.0 и не используется для показа текущего релиза.
