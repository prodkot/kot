# Изображения документации

`cover.svg` содержит фирменный баннер kot. и используется в начале главного README.

`overview-dark.png` показывает интерфейс 0.8.0 с демонстрационными данными. Он используется в главном README. Актуальные снимки сайта находятся в `site/assets` и сделаны с тем же тестовым мостом.

`routing-dark.png`, `geoip-dark.png` и `statistics-dark.png` иллюстрируют отдельные руководства. Это снимки интерфейса, а не доказательство сетевых измерений.
