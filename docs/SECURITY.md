# Безопасность

Обновления проверяются по RSA-ключу, встроенному в клиент. Setup содержит подписанный манифест с хешами установщика и пакета обновления. До изменения файлов проверяются обе части, версия и подписи файлов внутри пакета. Если новая версия не запустила интерфейс, обновлятор возвращает предыдущую. Setup не имеет подписи Authenticode, поэтому Windows может показывать предупреждение SmartScreen.

Профили и HWID защищены DPAPI текущего пользователя. Подписки загружаются по HTTPS. HWID не передаётся при перенаправлении на другой домен. Локальный API слушает только loopback и требует случайный ключ. Интерфейс не открывает внешние страницы и выводит названия серверов и логи как текст.

Kill switch использует постоянные фильтры Windows Filtering Platform. Падение приложения не удаляет фильтры. Добавление и замена проходят одной транзакцией. Блокируются исходящие и входящие прямые соединения вне интерфейса kot-tun для IPv4 и IPv6. Разрешены ядро sing-box, loopback и DHCP Windows. Остальные правила Windows Firewall не меняются. Защита не является загрузочным драйвером: ранняя загрузка Windows до службы фильтрации не покрывается. Прямые маршруты внутри ядра остаются прямыми, это не режим принудительного проксирования всех запросов ядра.

## Что ещё требует работы

- Интерфейс и ядро пока работают с правами администратора. Установка в Program Files снижает риск подмены файлов, но отдельная служба для ядра была бы лучше.
- Полное поведение на реальном Windows-компьютере при смене сети, сне и аварии питания требует ручной проверки. Нативные тесты проверяют реальные WFP-фильтры в изолированной области одного тестового процесса, а не обещают отсутствие любых утечек в любой сети.
- При сбое временные конфигурации могут остаться на диске. DPAPI не защищает от вредоносной программы, уже работающей от того же пользователя.
- Логи могут содержать адреса и личные сведения. Не публикуй их без просмотра.
- sing-box 1.14.2 содержит версии Go-модулей, совпавшие с шестью записями групп библиотек в базе OSV. Достижимость уязвимых участков в этом клиенте не установлена. Предыдущий подробный отчёт сохранён локально у издателя.

Секреты издателя не входят в репозиторий или Setup. GitHub Actions закреплены по SHA; ключ подписи доступен только заданию выпуска. Проверка истории публичного репозитория Gitleaks в 0.4.2 не нашла секретов. Проверки этой версии описаны в [BUILD.md](BUILD.md).
