# Безопасность

О сообщениях об уязвимостях и поддерживаемых версиях: [SECURITY.md](../SECURITY.md).

Обновления проверяются по RSA-ключу, встроенному в клиент. Setup содержит подписанный манифест с хешами установщика и пакета обновления. До изменения файлов проверяются обе части, версия и подписи файлов внутри пакета. Если новая версия не запустила интерфейс, обновлятор возвращает предыдущую. Setup не имеет подписи Authenticode, поэтому Windows может показывать предупреждение SmartScreen.

Профили и HWID защищены DPAPI текущего пользователя. Подписки загружаются по HTTPS. HWID не передаётся при перенаправлении на другой домен. Локальный API слушает только loopback и требует случайный ключ. Интерфейс не открывает внешние страницы и выводит названия серверов и логи как текст.

Мини-плеер загружает список только из API папки `prodkot/kot`, ветка `music`, а аудио только из соответствующей папки raw.githubusercontent.com. Токены, профиль и HWID туда не отправляются. Отдельная библиотека не обновляет код приложения. В демо сайта внешняя сеть, включая плеер, заблокирована.

Kill switch использует постоянные фильтры Windows Filtering Platform. Падение приложения не удаляет фильтры. Добавление и замена проходят одной транзакцией. Блокируются исходящие и входящие прямые соединения для IPv4 и IPv6. В режиме TUN разрешён интерфейс kot-tun; в режиме системного прокси разрешается только ядро и перечисленные ниже исключения. Разрешены ядро Xray, loopback и DHCP Windows. Остальные правила Windows Firewall не меняются. Защита не является загрузочным драйвером: ранняя загрузка Windows до службы фильтрации не покрывается. Прямые маршруты внутри ядра остаются прямыми, это не режим принудительного проксирования всех запросов ядра.

## Что ещё требует работы

- Интерфейс и ядро пока работают с правами администратора. Установка в Program Files снижает риск подмены файлов, но отдельная служба для ядра была бы лучше.
- Полное поведение на реальном Windows-компьютере при смене сети, сне и аварии питания требует ручной проверки. Нативные тесты проверяют реальные WFP-фильтры в изолированной области одного тестового процесса, а не обещают отсутствие любых утечек в любой сети.
- Конфигурации Xray передаются через stdin без временных файлов с ключами. DPAPI не защищает от вредоносной программы, уже работающей от того же пользователя.
- Логи могут содержать адреса и личные сведения. Не публикуй их без просмотра.
- Экспериментальная 0.8.0 собирает закреплённый официальный Xray из текущих исходников. Новая реализация TUN ещё требует длительных испытаний на разных Windows-компьютерах. Состав Go-модулей и лицензий приведён в `licenses/Xray-Go-NOTICES.txt`.

Секреты издателя не входят в репозиторий или Setup. GitHub Actions закреплены по SHA; ключ подписи доступен только заданию выпуска. Проверка истории Gitleaks выполняется при аудите репозитория; её результат относится к проверенным коммитам и не заменяет проверку следующих изменений. Проверки этой версии описаны в [BUILD.md](BUILD.md).
