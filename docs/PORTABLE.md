# Portable для тестирования 0.6.2

Распакуйте весь `Kot-Portable-0.6.2-Windows-x64.zip` в отдельную доступную для записи папку на локальном диске. Запускайте `Kot.Portable.exe`. Установщик не требуется: .NET, sing-box и Fixed Version WebView2 уже находятся внутри. TUN, zapret и kill switch требуют прав администратора, как и в обычном клиенте.

Окно и трей подписаны `kot. portable`, версия в интерфейсе отмечена `portable`. Сборка не читает профиль установленной 0.6.1 и не заменяет её файлы, ярлыки или задачу автозапуска. Это отдельное тестовое приложение из `dev/0.6.2`; main и опубликованный релиз не изменяются.

## Данные и удаление

Всё собственное состояние находится в `data` рядом с exe: зашифрованный профиль и HWID, статистика, WebView2 с кешем, GeoIP, временные файлы, распакованные .NET-компоненты дочерних программ, пакеты и журналы сервисов, выбор стратегий и история их проверок. Нет перехода на AppData при ошибке записи. Не переносите один exe без остальных файлов.

Перед удалением папки выберите **«Выход» в трее**, а не просто закройте окно с включённым «Закрывать в трей». Дождитесь завершения приложения и сервисов. Затем удалите всю распакованную папку: данные portable удалятся вместе с ней. Удаление только `data` после выхода сбрасывает настройки; следующий запуск начинает с пустого профиля.

Экспортированные вручную резервные копии, изображения и отчёты остаются в выбранном вами месте. Windows может сохранять обычные системные записи о запуске программ. Portable не является средством удаления истории Windows.

Профиль защищён Windows DPAPI и привязан к учётной записи Windows на этом компьютере. Для переноса подписок на другой компьютер используйте защищённую резервную копию в настройках.

## Сетевые функции

Системный прокси временно меняет настройки Windows и восстанавливает их при отключении, выходе или аварийном завершении. Portable использует собственную квитанцию восстановления в `data`. TUN имеет отдельное имя адаптера; одновременно подключать обычную и portable-версию к VPN не следует.

Kill switch portable блокирует прямой интернет при сбое ядра, пока работает само приложение. При завершении или аварии portable Windows удаляет его временные WFP-правила. Обычная установленная версия сохраняет прежнюю постоянную защиту.

Для zapret вспомогательный процесс удерживает управление только своим WinDivert и освобождает драйвер после остановки сервиса или завершения kot. Чужой драйвер не останавливается. Не запускайте одновременно несколько программ с общим WinDivert: при занятом чужом драйвере portable покажет ошибку. Удаление файлов не планируется через реестр на перезагрузку.

Автозапуск вместе с Windows и установка обновлений через Setup отключены. Сервисы можно обновлять и запускать вместе с kot, их настройки остаются в `data`. Для новой тестовой версии полностью завершите приложение, распакуйте новый portable-архив в отдельную папку и при необходимости перенесите `data` в рамках той же учётной записи Windows. Сам Fixed Version WebView2 обновляется только вместе с новым архивом.

## Сборка и проверки

На Windows с .NET SDK из `global.json`: `./Release/portable.ps1`. Получится архив и SHA-256 в `artifacts`; ключ подписи релиза и NSIS не нужны.

[Шаблон Windows portable development build](../Release/portable-development.workflow.yml) подготовлен в `Release` и пока не подключён к Actions. Для его переноса в `.github/workflows/portable-development.yml` требуется авторизация GitHub с правом `workflow`. После подключения он будет собирать только ветки разработки и хранить артефакт `windows-portable-development` 30 дней, без создания GitHub Release, тега или обновления сайта.

Нативные проверки подготовлены для настоящих WinForms/WebView2 и официальных пакетов сервисов: обе темы, окно 800x600, переход в статистику и обратно, сохранение профиля, отдельные данные, блокировка TCP временными WFP-правилами и их удаление после принудительного завершения процесса. Отдельный сценарий запускает распакованный self-contained exe из папки с пробелами и кириллицей, проверяет выход и полное удаление папки при неизменных данных установленной версии. Нативный запуск portable на Windows пока не подтверждён; успешные проверки обычной сборки и браузерного интерфейса его не заменяют. Эти проверки не доказывают обход блокировок у конкретного провайдера.
