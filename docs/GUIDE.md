# Как пользоваться

Установи Setup из [Releases](https://github.com/prodkot/kot/releases/latest). Нажми **+**, вставь ссылку на подписку или сервер и подключись.

В **Серверах** можно искать, добавлять в избранное и проверять пинг. **Авто** выбирает быстрый доступный сервер из избранного, а если оно пустое, из всего списка.

В **Логах** видны сообщения приложения и текущие соединения. Кнопка копирования собирает полный диагностический лог. Перед публикацией проверь его: там могут остаться адреса сайтов и другие личные сведения.

## Kill switch

Переключатель находится в **Настройках** и по умолчанию выключен. После начала подключения защита блокирует прямые соединения остальных программ вне туннеля, IPv4 и IPv6. Для работы ядра, локального API и DHCP есть исключения. Правила маршрутизации самого sing-box продолжают действовать, включая явно настроенные прямые маршруты.

При падении ядра, ошибке подключения или аварийном завершении kot. блокировка сохраняется. Открой kot. и подключись снова либо выключи Kill switch в настройках. При ручном отключении соединения и обычном выходе интернет разблокируется. Во время автоматического обновления защита сохраняется.

Если приложение не запускается, запусти от администратора:

```powershell
& 'C:\Program Files\Kot\Kot.exe' --disable-kill-switch
```

## Окно и трей

Свернуть оставляет окно на панели задач. Если включено **Закрывать в трей**, крестик скрывает окно. Левый клик по иконке трея открывает kot., правый открывает меню. Полный выход находится в этом меню.

## Обновления

В **Настройки → Обновления** уже указан `prodkot/kot`. Включённая автоматическая установка проверяет релизы при старте и раз в сутки, скачивает Setup, проверяет подписи и обновляет программу в её текущей папке. Выбирать папку не нужно. Подписки, настройки и HWID сохраняются; активное соединение восстанавливается после перезапуска.

Версия 0.4.2 и более ранние искали ZIP. Для перехода на 0.5.0 нужно один раз запустить новый Setup. Следующие обновления уже работают через Setup.

Резервная копия доступна в **Настройки → Дополнительно**. Файл содержит данные подписок, храни его как пароль. HWID можно посмотреть и скопировать в **Настройки → HWID**.
