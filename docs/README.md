## Получить помощь

Для воспроизводимой ошибки или предложения открой [issue](https://github.com/prodkot/kot/issues/new/choose). Версия клиента, версия Windows, шаги и очищенный лог помогут быстрее разобраться. Ссылки подписок, ключи, пароли и HWID не публикуй.

Об уязвимостях сообщай [приватно](../SECURITY.md). Изменения по версиям собраны в [CHANGELOG.md](../CHANGELOG.md).
