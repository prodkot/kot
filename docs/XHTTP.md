# XHTTP

В разрабатываемой версии 0.7.0 kot поддерживает XHTTP у серверов VLESS, VMess и Trojan. Сервер должен быть настроен на XHTTP: добавление транспорта в клиент не меняет настройки сервера.

## Подключение

Добавьте обычную ссылку или подписку на странице «Серверы». В ссылках VLESS и Trojan используется `type=xhttp`, в JSON-ссылках VMess `net=xhttp`. Старое имя `splithttp` также принимается и при экспорте нормализуется в `xhttp`.

Поддерживаются `host`, `path`, режимы `auto`, `packet-up`, `stream-up`, `stream-one` и JSON-параметры `extra`. По умолчанию путь `/`, режим `auto`. Ссылки, QR, резервные копии и Clash YAML сохраняют эти параметры. В Clash используется `network: xhttp` и блок `xhttp-opts` с `host`, `path`, `mode`, `extra`.

Доступны обычные TLS с проверкой сертификата, а для VLESS также REALITY с ключом, SNI, short ID и отпечатком клиента. У VLESS с XHTTP поле `flow` должно быть пустым. Отключение проверки сертификата не поддерживается.

В `extra` принимаются параметры padding, HTTP-заголовки, настройки uplink, интервалы и размеры POST, `xmux` и отдельные `downloadSettings` для XHTTP с TLS или REALITY. Параметры проверяются перед сохранением. Ссылки с неизвестными опциями, внешними файлами, цепочками через `dialerProxy` или отключённой проверкой TLS отклоняются с объяснением. `Host` задаётся отдельным полем `host`, а не внутри `headers`.

Для VLESS можно явно задать `packetEncoding=xudp` в ссылке, для VMess `"packetEncoding": "xudp"` в JSON. Формат `packetaddr` и XUDP у Trojan не поддерживаются. Обычный UDP доступен и без этого параметра.

## Режимы и ядра

XHTTP работает в TUN и в системном прокси. HTTP-пинг, диагностика, выбор «Авто», маршрутизация и статистика используют тот же сервер.

В Setup включён официальный Xray 26.3.27 без изменений. Для соединения с XHTTP kot запускает его отдельным управляемым процессом, а sing-box сохраняет TUN, маршрутизацию, DNS и статистику. Серверы с другими транспортами продолжают использовать sing-box напрямую. В смешанном списке «Авто» оба варианта могут участвовать в выборе.

Локальная связь между ядрами слушает только `127.0.0.1` и защищена случайными учётными данными. Каждый XHTTP-сервер получает отдельный порт, чтобы TCP и UDP попадали в нужный сервер. Файл с параметрами удаляется после запуска, процессы завершаются при отключении и закрытии приложения. При аварийной остановке Xray соединение закрывается; прямой маршрут вместо выбранного VPN не используется.

Для предотвращения зацикливания TUN исключает точный путь комплектного `xray.exe`. Kill switch разрешает этот процесс только в соединениях, которым нужен XHTTP; при следующем соединении без XHTTP исключение убирается. Для HTTP-пинга Xray получает временное разрешение, которое удаляется после последней параллельной проверки; активная защита и правила TUN сохраняются. Другие прямые правила, явно выбранные пользователем, сохраняют свой обычный смысл.

## Проверки

`Tests/XhttpTests.cs` проверяет импорт, экспорт, резервные копии, ограничения параметров и конфигурации. `Tests/xhttp_integration.py` проверяет реальные локальные цепочки sing-box, Xray и XHTTP для всех четырёх режимов, TLS, REALITY, HTTP и UDP, отдельный download, XUDP, обязательную авторизацию и отказ при неверном TLS-имени или остановке ядра. Для запуска сначала создайте фикстуры:

```sh
dotnet run --project Tests/Kot.Tests.csproj -c Release -- integration
python3 Tests/xhttp_integration.py --core /path/to/sing-box --xray /path/to/xray
```

На Windows тест `Kot.WindowTests.exe --xhttp-test /path/to/sing-box.exe /path/to/xray.exe` дополнительно проверяет запуск и очистку нативных процессов, отмену, отклонённую конфигурацию, реальный TUN и правила WFP. Тест также входит в существующую команду `--tunnel-test` и запускается при сборке development Setup и релиза. Linux-команда `Tests/integration.py` запускает всю матрицу XHTTP, скачивая официальный бинарный файл с проверкой закреплённого SHA256.

Официальная документация: [транспорт XHTTP](https://xtls.github.io/en/config/transports/xhttp.html). Версии, лицензии и точные исходники перечислены в [THIRD-PARTY.txt](../THIRD-PARTY.txt).
