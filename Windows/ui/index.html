Автоматизация


Восстанавливать соединение




0 отключает обновление или фоновый пинг. «Авто» выбирает из избранного, если оно есть. Допуск уменьшает лишние переключения.


Резервная копия
От 8 символов. Сохраняются все подписки и настройки. Восстановление заменит текущий профиль и отключит соединение; HWID этого компьютера останется прежним.


Обновления
Проверка обновлений


Проверка при запуске и раз в сутки. Загрузка и установка начнутся только после нажатия «Обновить». Приложение перезапустится и восстановит активное соединение.


Удалить подписку?
Будет удалена текущая подписка. Остальные останутся.



Маршрутизация





По умолчанию трафик идёт через VPN, локальная сеть напрямую. Прямые домены из дополнительных настроек продолжают работать. Создайте профиль, чтобы задать свои правила.












Домены без https:// и путей, по одному в строке. Правило распространяется на поддомены.






IPv4, IPv6 или подсети в формате CIDR. Локальная сеть всегда остаётся доступна напрямую.






Имена .exe без пути, по одному в строке. Для всего трафика приложения используйте TUN. Системный прокси принимает только трафик приложений, которые используют настройки прокси Windows.






Двухбуквенные коды стран, по одному в строке: RU, US, CN, GB. Базы загружаются при сохранении. GeoIP определяет страну IP-адреса сервера; сайт с CDN может находиться в другой стране.




DNS-запросы шифруются. Приоритет правил: блокировка, приложения, сайты, IP, страны, затем остальной трафик. Проверка сервера всегда идёт через VPN.


Обновление по ссылке
Новая ссылка загружает правила при сохранении. Обновления заменяют правила содержимым ссылки. 0 отключает автообновление; пустая ссылка сохраняет профиль локально.







Импорт маршрутизации
Ссылка включает автообновление раз в 24 часа. Вставленный JSON сохраняется локально. Нужен профиль в формате kot.

По умолчанию раз в сутки. 0 отключает автообновление. При изменении базы активное соединение переподключится.

Удалить сервис?
Управляемый процесс будет остановлен, его пакет и журнал удалены. Настройки kot и результаты подбора сохранятся.
