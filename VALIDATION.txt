Проверки kot. 0.4.2
7 октября 2026

Для этого выпуска добавлены Windows-проверки поведения окна и реального
меню трея. Проверяются системные команды сворачивания, сохранение
развёрнутого размера, открытие скрытого окна, состояния меню и быстрый
переход к логам. Скриншоты меню сохраняются из WinForms, без макета HTML.

Основные тесты проверяют подписки, HWID, конфигурации, резервные копии,
сетевые ограничения, подпись обновлений и откат. Новые проверки
ограничивают ответ локального API до 64 КиБ и проверяют отмену чтения.
Проверки нативного запуска дочернего процесса сохранены.

Интерфейс проверяется в Chromium через тестовый мост: темы, цвета,
размеры окна, настройки, пинг, логи, HWID и действия обновлений.
Это проверка фронтенда, а не настоящее окно WebView2 на компьютере.

Результат сборки и Windows-проверок доступен в GitHub Actions:
https://github.com/prodkot/kot/actions

При выпуске ZIP проходит штатную проверку закреплённой RSA-подписи,
версии, путей и SHA-256 файлов. Контрольные суммы опубликованных файлов
проверяются после загрузки из GitHub Releases.

Ограничения проверки

Автоматическая Windows-проверка отправляет настоящие системные команды
окну. Она не нажимает физическую кнопку панели задач в Explorer.
Поведение на нескольких мониторах, разные масштабы Windows, UAC,
установка и удаление через окно установщика требуют ручной проверки.

Не проверены живой TUN, утечки DNS/IPv6, сон, смена сети и весь переход
между старым приложением, помощником обновления и новым WebView2.
При сбое питания во время замены файлов нет полного автоматического
восстановления. Поэтому выпуск остаётся beta.
