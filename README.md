# Музыка kot.

Эта ветка содержит только библиотеку мини-плеера. Код клиента находится в `dev/xray-core`.

Открой [загрузку файлов](https://github.com/prodkot/kot/upload/music/music), перетащи MP3 или OGG и сохрани изменения в ветку `music`.

До 20 МиБ на трек, до 100 файлов. Не создавай вложенные папки. Имена файлов становятся названиями треков. Пересборка приложения не нужна; список обновляется при открытии «О приложении», не чаще раза в пять минут.

Все файлы общедоступны. Добавляй музыку, которую можно распространять.
