# kot.

Приложение для Windows на базе sing-box. Подписки, серверы и подключение без лишней возни.

**[Скачать](https://github.com/prodkot/kot/releases/latest)** · [Сайт](https://prodkot.github.io/kot/) · [Что нового](CHANGELOG.md)

![Главный экран kot.](docs/images/home-dark.png)

*Сервер и значения на скриншоте приведены для примера.*

1. Установи kot. через Setup.
2. Нажми **+** и добавь свою подписку или ссылку на сервер.
3. Выбери сервер и нажми **Подключить**.

Есть избранное, пинг, логи, скорость сети, светлая тема и обновления с GitHub.

Kill switch включается в настройках. При сбое он блокирует прямой интернет до повторного подключения или отключения защиты. Кнопка «Отключить» и обычный выход снимают блокировку.

Нужна Windows 10 или 11, x64. Серверы и подписки в комплект не входят.
