# Сайт kot.

Адрес: <https://prodkot.github.io/kot/>.

Статический HTML, CSS и JavaScript без сторонних библиотек и внешних шрифтов. Сайт использует Manrope из приложения; сборка копирует единственный файл шрифта из `Windows/ui/fonts` вместе с лицензией OFL.

На главной есть скачивание актуального Setup, интерактивное демо, сценарий работы в фоне, переключаемые снимки интерфейса, быстрый старт и ответы на вопросы. Ссылки на руководства ведут в общий [раздел документации](../docs/README.md). Клавиатура переключает снимки стрелками, Home и End; демо разворачивается без перезагрузки и закрывается по Escape. Отключённый JavaScript оставляет снимок главного экрана и рабочую ссылку на последний релиз.

## Демо

Собирается из настоящего интерфейса `Windows/ui`. Данные серверов, подключения и трафика демонстрационные. Оно не подключается к сети, не читает HWID, не меняет системные настройки и хранит состояние только до перезагрузки. Встроенный фрейм изолирован песочницей и CSP, сброс очищает его состояние.

## Локальная проверка

```sh
python3 site/build.py --output artifacts/site
python3 -m http.server 8000 --directory artifacts/site
```

Открой <http://localhost:8000>. Для проверки сборки и ресурсов запусти `python3 site/check.py`. `site/demo_browser_check.py` использует Playwright и Chromium: проверяет вкладки сайта, загрузку снимков, актуальный установщик, взаимодействия в демо, изоляцию, полноэкранный режим, мобильные размеры, уменьшение движения и работу без JavaScript. Зависимости описаны в [сборке и тестах](../docs/BUILD.md).

`release.json` служит для локального просмотра и описывает последний опубликованный Setup, а не ещё не выпущенную версию из исходников. Сейчас это 0.7.1. В Actions метаданные берутся из GitHub API; имя, версия и ссылка на установщик проверяются перед сборкой. В браузере ссылка дополнительно проверяется; при ошибке остаётся страница последнего релиза.

## Изображения

Снимки `assets/home.png`, `servers.png`, `statistics.png`, `connections.png` и `settings.png` показывают HTML-интерфейс 0.7.1. Они сняты в Chromium с тестовым WebView-мостом из [Tests/statistics_ui.py](../Tests/statistics_ui.py): соединение, серверы, пинг и трафик заданы для примера. Нативное окно Windows и реальную сеть снимки не проверяют. Главный экран совпадает с `docs/images/overview-dark.png` (окно 960 × 640), остальные сняты при 960 × 720, масштаб всех снимков 1,5. Настройки показаны в светлой теме, остальные экраны в тёмной. Обновляй версию в подписях и все снимки вместе при изменении интерфейса.

`assets/social.png` размером 1200 × 630 используется в превью ссылки: надпись Manrope и актуальный абстрактный знак из [Brand](../Brand/README.md). Иконка сайта использует тот же знак. Демонстрационные значения на снимках не являются измерением скорости или задержки настоящего сервера.

GitHub Actions публикует сайт после изменений в его исходниках и после успешного выпуска новой версии. Код сайта доступен по MIT, шрифт по SIL OFL 1.1.
