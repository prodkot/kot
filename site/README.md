# Сайт kot.

[prodkot.github.io/kot](https://prodkot.github.io/kot/) содержит скачивание, демо, возможности и быстрый старт. Вступление совпадает с [README](../README.md); технические подробности находятся в [документации](../docs/README.md).

```sh
python3 site/build.py --output artifacts/site
python3 -m http.server 8000 --directory artifacts/site
python3 site/check.py
python3 site/demo_browser_check.py
```

Демо собирается из `Windows/ui` с тестовыми данными. CSP и sandbox блокируют внешнюю сеть, включая музыку. Демо не меняет настройки компьютера. Его версия берётся из исходников, а стабильная загрузка из GitHub Releases. При ошибке метаданных остаётся ссылка на страницу релиза. `release.json` нужен для локального просмотра.

Снимки интерфейса 0.8.0 используют демонстрационные данные. `assets/home.png` служит запасным экраном без JavaScript; три вкладки показывают серверы, статистику и настройки. Шрифт и его лицензия копируются из клиента при сборке. Проверки покрывают загрузку ресурсов, клавиатуру, мобильные размеры, демо и отсутствие JavaScript.

GitHub Pages публикует `main` после изменений сайта или стабильного релиза. Экспериментальные релизы не запускают публикацию. Красный старый deployment не означает, что текущий сайт недоступен.
