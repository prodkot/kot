# Сайт kot.

[prodkot.github.io/kot](https://prodkot.github.io/kot/) показывает пять экранов клиента, открывает интерактивное демо и скачивает стабильный установщик для Windows. Описание для поисковиков совпадает с [README](../README.md); подробности находятся в [документации](../docs/README.md).

```sh
python3 site/build.py --output artifacts/site
python3 -m http.server 8000 --directory artifacts/site
python3 site/check.py
python3 site/demo_browser_check.py
python3 site/viewer_browser_check.py
```

Для браузерных проверок нужны Playwright и Chromium. Сборка и обычные проверки используют стандартную библиотеку Python.

Сборка проверяет происхождение установщика и подставляет прямую ссылку в обе кнопки, в том числе для посетителей без JavaScript. GitHub Pages получает актуальные метаданные стабильного релиза; `release.json` используется для локальной сборки. Неверные метаданные останавливают сборку, текущая опубликованная версия остаётся доступной. В исходном HTML кнопки ведут на страницу последнего релиза.

Демо собирается из `Windows/ui` с примерными данными и загружается только при открытии. Его версия берётся из исходников клиента. CSP и sandbox блокируют внешнюю сеть, включая музыку. Демо не меняет настройки компьютера и сохраняет состояние при закрытии и повторном открытии окна; кнопка сброса создаёт новый экземпляр.

Снимки интерфейса 0.8.0 находятся в `assets/screens/`. Галерея переключается сама через 5,2 секунды. После ручного выбора, свайпа или стрелок она ждёт 5 секунд от последнего действия. Открытое окно демо или снимка, скрытая вкладка и удержание указателя останавливают показ. При `prefers-reduced-motion` автоматическое переключение и декоративное движение отключены.

Кота можно погладить кликом, касанием или клавишей Enter/Space. Значок нажатия подсказывает действие без подписи; движение указателя само по себе поглаживание не запускает. На 5 секунд появляется «Мяу, и интернет у тебя в руках.», повторное действие продлевает показ. Клубок реагирует на указатель и касание, сохраняя вертикальную прокрутку. Точки рядом с белым текстом зелёные и квадратные, рядом с зелёным текстом белые и квадратные. Версии, адреса и исходные снимки не преобразуются.

Шрифты и их лицензии включены в `assets/fonts/`. Проверки покрывают относительные пути GitHub Pages, установщик, ресурсы, клавиатуру, таймеры, мобильные размеры, кота, изоляцию демо, уменьшенное движение и работу без JavaScript.

GitHub Pages публикует `main` после изменений сайта или стабильного релиза. Экспериментальные релизы не запускают публикацию.
